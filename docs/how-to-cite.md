# How to cite

!!! info "Placeholder"
    A DOI will be added at the first tagged release.

If you use this handbook, please cite it. The repository has a
[`CITATION.cff`](https://github.com/mantas123456/measurement-uncertainty-handbook/blob/main/CITATION.cff)
file, so GitHub's *Cite this repository* button gives APA and BibTeX.

> Valantinavičius, M. (2026). *Measurement Uncertainty Handbook* (Version 0.1.0).
> https://mantas123456.github.io/measurement-uncertainty-handbook/

To cite the calculations, also cite the `labqc` package version you used.
