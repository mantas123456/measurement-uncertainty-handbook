# Measurement Uncertainty Handbook

A free, practical guide to **method validation and measurement uncertainty** for
ISO/IEC 17025 testing laboratories. Each topic opens with the practical
question it answers, then the formula, the Python code and the interpretation.

!!! warning "Work in progress"
    This handbook is in its first draft (v0.1 in preparation). Chapters marked
    *Planned* have no content yet.

## What is here

| Chapter | What it answers |

Every calculation comes from [`labqc`](https://pypi.org/project/labqc/), an open
Python package tested against published worked examples. All data are synthetic
and generated by a seeded script; no real laboratory data are used.

## Related free tools

This handbook links to existing tools rather than replacing them:

- [NIST Uncertainty Machine](https://uncertainty.nist.gov/): GUM and Monte Carlo propagation in the browser
- Nordtest MUkit: top-down uncertainty from QC and PT data
- [`uncertainties`](https://pypi.org/project/uncertainties/) (Python) and
  [`metRology`](https://cran.r-project.org/package=metRology) (R)

Its own angle is transparent, tested Python with a practitioner's explanations,
covering the whole path from method validation to the reported result.

## Disclaimer

Educational material. It is not a substitute for your laboratory's own validated
procedures or your accreditation body's guidance. ISO standards are cited by
number and clause only.
